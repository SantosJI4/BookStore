# BookStore - EBAC 2026

A Bookstore API é uma aplicação desenvolvida em Django e Django REST Framework para gerenciar uma livraria digital.
Ela fornece endpoints para cadastro, consulta e gerenciamento de livros, autores e usuários, permitindo integração com sistemas externos ou aplicações frontend.

## ✨ Funcionalidades principais
- 📚 Gerenciamento de livros: criar, listar, atualizar e excluir registros.
- ✍️ Controle de autores: vincular autores aos livros e manter seus dados atualizados.
- 👤 Usuários e autenticação: suporte a cadastro e login de usuários com segurança.
- 🔍 Filtros e buscas: pesquisa avançada por título, autor ou categoria.
- 🧪 Testes automatizados: integração com pytest e factory-boy para garantir qualidade.
- 🎭 Dados fictícios: uso do Faker para popular o banco em ambiente de desenvolvimento.
🚀 Tecnologias utilizadas
- Django 6.0
- Django REST Framework
- Pytest para testes
- Factory Boy e Faker para geração de dados
- Poetry para gerenciamento de dependências
